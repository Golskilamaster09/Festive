# 🎉 Festive

Uma aplicação web moderna e responsiva voltada para a divulgação, organização e experiência visual de eventos e festividades, desenvolvida com foco em design atraente, boa usabilidade e fidelidade de interface.

---

## 🎯 Sobre o Projeto

O **Festive** foi concebido para apresentar informações de eventos de forma dinâmica, elegante e acessível. A interface foi planeada para oferecer uma navegação intuitiva, destacando detalhes importantes da celebração/evento, cronograma, confirmação e integração visual.

### Destaques:
- **Design Moderno e Imersivo:** Paleta de cores e tipografia pensadas para transmitir o ambiente festivo do evento.
- **Estrutura Responsiva:** Interface totalmente adaptada para dispositivos móveis, tablets e computadores de secretária.
- **Componentização e Boas Práticas:** Código limpo, semântico e estruturado para fácil manutenção e escalabilidade.

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica e acessibilidade.
- **CSS3:** Flexbox, CSS Grid, variáveis nativas (Custom Properties) e transições suaves.
- **JavaScript:** Manipulação da DOM, controlo de estados de interface e interatividades dinâmicas.

---

## ✨ Funcionalidades

- [x] **Hero Section:** Seção inicial de impacto com chamada para ação (CTA).
- [x] **Detalhes do Evento:** Apresentação clara de datas, locais, atrações e programação.
- [x] **Layout Fluido:** Adaptação suave em diferentes resoluções e ecrãs.
- [x] **Microinterações:** Efeitos de hover e feedback visual ao utilizador.
